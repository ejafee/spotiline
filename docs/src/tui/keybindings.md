# Keyboard Bindings

## Navigation Mode

| Key | Action |
|-----|--------|
| `q` | Quit |
| `Space` | Play / Pause |
| `n` | Next track |
| `p` | Previous track |
| `←` | Seek backward 10s |
| `→` | Seek forward 10s |
| `↑` / `↓` | Navigate lists |
| `Enter` | Play selected track |
| `Tab` | Switch focus (playlists ↔ tracks) |
| `/` | Enter search mode |

## Search Mode

| Key | Action |
|-----|--------|
| `Esc` | Exit search |
| `Enter` | Play first result |
| `Backspace` | Delete character |
| `↑` / `↓` | Navigate results |
| Any char | Type to search (live results) |
